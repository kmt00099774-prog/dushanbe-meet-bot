# Читай и учи

Мобильное приложение (iOS и Android) для чтения книг на английском с переводом слов на русский.

## Что умеет

- **Чтение.** Нажмите на любое слово, и над ним появится карточка: озвучка 🔊, транскрипция и перевод.
- **«Знаю» / «Учить».** «Учить» добавляет слово в личный словарь вместе с предложением из книги.
- **«Слушай».** Глава читается вслух, текущий абзац подсвечивается.
- **«Мои слова».** Здесь все отложенные слова, их прогресс и дата следующего повтора. Есть вкладка «Выученные».
- **«Тренировка».** Карточки с интервальным повторением: 0 → 1 → 3 → 7 → 14 → 30 дней. Если ответить «Помню» на всех этапах, слово попадёт в «Выученные». Если ответить «Не помню», слово начнёт повторяться заново.
- Данные хранятся на телефоне (AsyncStorage).

Встроенный словарь покрывает все слова встроенных книг. Если слова нет в словаре, приложение переводит его онлайн (MyMemory, dictionaryapi.dev).

## Запуск

```bash
cd word-app
npm install
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** на телефоне.

Сборка APK или IPA: `npx eas-cli@latest build -p android` (или `-p ios`).

## Как добавить книгу

Добавьте объект в `src/data/books.ts`. Переводы новых слов можно внести в `src/data/dictionary.ts` в формате `слово|транскрипция|перевод`.
